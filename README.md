# Machine Learning and AI Project Catalog

This repository collects small projects covering supervised learning, computer vision, recommendation systems, MLOps, retrieval-augmented generation, and reinforcement learning. The catalog below summarizes the purpose, workflow, outputs, and meaningful technologies evidenced by each project.

| Project | Description | Technologies |
|---|---|---|
| [Adult Income Classification](AdultIncomeClassification/README.md) | This project predicts whether an individual's annual income is `>50K` or `<=50K` from demographic and employment attributes in the UCI Adult/Census Income dataset. Its workflow includes exploratory analysis of distributions, missing values, class imbalance, and feature relationships; cleaning the dataset's `?` values; and a leakage-conscious preprocessing pipeline that imputes missing values, one-hot encodes categorical fields, and scales numeric fields. Redundant or non-predictive columns are removed before modeling.<br><br>Logistic Regression provides a baseline and a Random Forest is evaluated alongside it, with balanced class weights and five-fold cross-validation using F1 as the selection metric rather than relying on accuracy alone. The project also produces precision/recall/F1, ROC-AUC, confusion-matrix, and feature-importance analyses, persists the selected pipeline, and exposes single-person prediction through a Streamlit interface. | Python, pandas, NumPy, scikit-learn (`ColumnTransformer`, `Pipeline`, Logistic Regression, Random Forest), matplotlib, seaborn, joblib, Streamlit |
| [Cancer Classification from Gene Expression Data](CancerClassificationML/README.md) | This pipeline classifies RNA-Seq gene-expression profiles into five cancer types: BRCA, KIRC, LUAD, PRAD, and COAD. It starts with 801 samples and 20,531 anonymized gene features, performs an 80/20 stratified split before calculating feature statistics, removes train-set zero-variance genes, applies a `log2(x+1)` transform and train-fitted standardization, and compares PCA, ANOVA SelectKBest, and variance/correlation filtering for dimensionality reduction. The modeling stage tunes SVM, Random Forest, XGBoost, and MLP classifiers with stratified `RandomizedSearchCV`, then evaluates held-out predictions using macro-F1, accuracy, classification reports, and confusion matrices.<br><br>The project also demonstrates model interpretability by combining tree-based importances, SHAP analyses, and MLP permutation importance to rank discriminative genes. The resulting top 25 genes are used to retrain a compact deployment model, with the scaler subset and label order packaged alongside the model. A Streamlit frontend accepts 25 expression values or loads example patient profiles, displays the predicted cancer class and confidence distribution, and is intended for deployment on Render; it is explicitly an educational benchmark application rather than a clinical diagnostic tool. | Python, pandas, NumPy, scikit-learn, XGBoost, imbalanced-learn, SHAP, joblib, Streamlit, Render |
| [CIFAR-10 Image Classification](Cifar10ImageClassification/README.md) | This computer-vision project trains a convolutional neural network from scratch to classify 32×32 RGB images into the ten CIFAR-10 categories: airplane, automobile, bird, cat, deer, dog, frog, horse, ship, and truck. It covers dataset loading, normalization, label preparation, train/validation handling, and augmentation, followed by evaluation with test metrics, a classification report, a confusion matrix, and sample predictions. The trained model and class names are persisted for later inference.<br><br>The network is organized as three progressively wider convolutional blocks using Conv2D, BatchNorm, MaxPool, and Dropout, followed by a dense classification head. Random flip, rotation, translation, and zoom layers are active during training, while Adam, categorical cross-entropy, early stopping, and learning-rate reduction on plateau control optimization. Separate scripts support single-image prediction and prediction grids, and a Streamlit app provides interactive image classification. | Python, TensorFlow/Keras, CNNs, NumPy, scikit-learn, matplotlib, seaborn, Pillow, Streamlit |
| [Chatbot RAG](Chatbot-RAG/README.md) | This project implements a document-grounded question-answering chatbot for user-provided `.txt` and `.pdf` files. The Flask web interface accepts uploads, saves them to the data area, loads and cleans their text, splits the content into chunks, generates embeddings, builds a persistent FAISS index, and then exposes a question endpoint. For a question, the retriever selects the most relevant chunks, the RAG engine inserts those chunks into a prompt that instructs the language model to use only supplied context, and the response includes source filenames, chunk identifiers, and similarity scores for citation. Empty questions, unsupported file types, missing indexes, and processing failures are returned as explicit API errors.<br><br>The repository contains the full modular pipeline—loading, chunking, embedding, vector storage, retrieval, LLM generation, and the two-pane browser interface—but its README also describes the work as a staged roadmap, and the exact provider configuration is delegated to the implementation. The design therefore demonstrates the RAG architecture and source-grounding behavior without claiming a particular production model or deployment. | Python, Flask, pypdf, LangChain text/document utilities, Sentence Transformers, FAISS, OpenAI API, Ollama, Google GenAI |
| [CartPole RL Agent](cartpole-rl-agent/README.md) | This reinforcement-learning project trains a policy to solve Gymnasium's classic CartPole-v1 control task. A Proximal Policy Optimization agent learns from environment rewards rather than hand-coded control rules, with training configured through command-line timesteps and an early stopping condition once the moving average reward reaches the environment's solved threshold. The project saves the best model and provides a separate evaluation path for measuring the trained policy.<br><br>Supporting scripts turn the experiment into a reproducible workflow: learning-curve plotting, live rendering of the agent, and episode-video recording are separated from training and evaluation. The README does not contain completed numerical results—the PPO reward and timesteps-to-solve fields remain marked TBD—so the catalog describes the experiment and its artifacts without asserting an achieved score. | Python, Gymnasium, Stable-Baselines3, PPO, reinforcement learning, Matplotlib/Pandas for learning curves |
| [Iris MLOps API](IrisMLOps/README.md) | This project demonstrates an end-to-end machine-learning delivery path for Iris flower classification. A training script fits a Scikit-learn RandomForestClassifier on the Iris dataset, records evaluation metrics, and serializes the model artifact. A Flask REST service loads that artifact and validates prediction input through a schema module, exposing a health endpoint and a JSON `POST /predict` endpoint that maps sepal and petal measurements to a flower class. The API also returns clear responses for missing or invalid fields, unsupported routes/methods, and unexpected failures.<br><br>The same application is packaged with Docker and served in production through Gunicorn, with a documented Render deployment and cURL/Postman testing workflow. The project therefore focuses on the operational lifecycle around a small model—training, artifact management, validation, HTTP serving, containerization, and public deployment—rather than only on classifier development. | Python, scikit-learn, RandomForestClassifier, Flask, schema-based input validation, Gunicorn, Docker, Render, REST/JSON, cURL, Postman |
| [LunarLander PPO](LunarLander-PPO/README.md) | This project trains an autonomous lander controller with PPO in Gymnasium's LunarLander-v3 Box2D environment. The policy observes an eight-value state containing position, velocity, angle, angular velocity, and leg-contact information, then selects among four discrete actions: no thrust, left engine, main engine, or right engine. Reward feedback favors proximity to the landing pad, upright and gentle descent, and leg contact while penalizing crashes, drift, instability, and excessive fuel use.<br><br>Training is centralized through a configuration module and is resumable and chunked: each run can continue from the latest model, save periodic checkpoints, and retain the best evaluation model. Separate tools evaluate mean and standard-deviation rewards over deterministic episodes, render live episodes, record MP4 demonstrations, and parse monitor logs into reward graphs. The project documents expected learning behavior and evaluation bands but does not claim a fixed final score. | Python, Gymnasium, Box2D, Stable-Baselines3, PPO, PyTorch, NumPy, Pandas, Matplotlib, MoviePy |
| [Movie Recommendation System](MovieRecommendationSystem/README.md) | This application provides content-based movie recommendations from the MovieLens `ml-latest-small` dataset. It cleans each movie's pipe-separated genre list, aggregates rating statistics for display, and represents the genre text with TF-IDF vectors. Pairwise cosine similarity is computed from those genre vectors, then persisted in pickle artifacts so the interactive application can retrieve recommendations without rebuilding the matrix on every launch. Ratings are shown as context only and do not affect similarity scoring.<br><br>The Streamlit interface lets a user search for a movie, select the number of results, and view recommended titles with genre tags and available average-rating information. The accompanying notebook documents exploratory analysis, preprocessing, vectorization, similarity testing, and recommendation checks. The intentionally limited design does not use collaborative filtering, deep learning, embeddings, LLMs, a database, or external runtime APIs. | Python, pandas, NumPy, scikit-learn TF-IDF and cosine similarity, Streamlit, pickle, Jupyter |
